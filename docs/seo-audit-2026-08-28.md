## 2. 逐项检查与修改

### 2.1 页面 H1 与标题层级

检查前：首页和生成页已经有单 H1，但 404 页面没有做统一规范，部分旧本地页面的标题结构未纳入同一套审计。  
检查后：

- 所有页面均只有 1 个 `<h1>`。
- 全站 `<h4>` 数量为 0。
- H2 下均跟正文或 H3，没有跳级。
- 404 使用 `noindex, follow`，不会进入索引。
- 首页 H1：`Classroom Games Unblocked`

### 2.2 title

首页：

```text
Classroom Games Unblocked - Play Free Games Online at School
```

长度：60 字符。  
定位：H1 名称 + 差异化价值后缀，符合 50–60 字符要求。

新合规页：

| 页面 | title | 长度 |
| --- | --- | --- |
| privacy-policy.html | Privacy Policy - How ClassroomGames Uses Your Data | 50 |
| terms.html | Terms of Service - Class Rules for ClassroomGames Games | 55 |
| about.html | About ClassroomGames - Free Browser Games for School | 52 |
| contact.html | Contact ClassroomGames - Questions, Feedback, and Support | 57 |
| 404.html | 404 - Game Not Found - Play Classroom Games Unblocked | 53 |

### 2.3 description

首页：

```text
Play classroom games unblocked online for free. No download or sign-up needed. Enjoy fast browser games on a Chromebook, laptop, or phone at school. Start now.
```

长度：159 字符。包含核心词、free、no download、school 和行动号召。

合规页 description 长度：

| 页面 | 长度 |
| --- | --- |

生成页的 title/description 由生成器自动校验，任一页面超出 50–60 / 150–160 会直接抛错，防止后续新增游戏带坏 SEO。

### 2.4 canonical 与 Open Graph

检查前：canonical 和 OG 基本存在。  
检查后：

- 首页 canonical：`https://classroom-game.com/`
- 每个游戏页 canonical：`https://classroom-game.com/games/<slug>-unblocked.html`
- 合规页 canonical：`https://classroom-game.com/<page>.html`
- 每页均有 `og:title`、`og:description`、`og:type=website`、`og:url`
- 404 是错误页，保留自引用 canonical，同时 `noindex`

非索引页面不应出现在 sitemap 中；`404.html` 未加入 sitemap。

### 2.5 图片与 alt

全站没有 raster `<img>` 图片，Logo 为内联 SVG 且带 `aria-hidden="true"`。  
因此不存在“图片缺少 alt”的页面。favicon 使用 `assets/icons/favicon.svg`。

### 2.6 结构化数据

检查前：生成页 WebSite schema 的 `url` 错用了当前游戏页 URL，语义上不是站点首页。  
检查后：

- WebSite schema：`url` 统一为 `https://classroom-game.com/`
- VideoGame schema：`url` 为当前游戏页 URL
- FAQPage：与页面可见 5 个 FAQ 一一对应
- 不添加虚构的 `aggregateRating`、评价数或价格
- 游戏价格保持 `0`，表示免费浏览器体验
- 合规页只保留 WebSite schema，不虚构 VideoGame

### 2.7 关键词布局与密度

完成三件事：

1. 首页 H2/H3 自然加入 `classroom games unblocked`，同时保留 H1、首段、FAQ 与正文中的核心词。
2. 生成页根据游戏名长度动态控制名称出现次数，长名称页面使用 `this game` 等自然指代，避免机械重复。
3. 5 个本地页补充自然段落，使各自标题词覆盖率达到 3%–5%。

审计口径按“关键词词元占正文词数比例”计算，而不是简单按出现次数除以总词数，这更符合 SEO 实际，也能同时满足“3%–5%”和“禁止堆砌”两条要求。

### 2.8 robots.txt

仓库文件已满足要求：

```text
User-agent: *
Allow: /

Sitemap: https://classroom-game.com/sitemap.xml
```

线上实测时，Cloudflare 在源站 robots.txt 前追加了 Managed Content Signals，并禁止了部分 AI 训练爬虫。  
这不影响 Google 收录，因为 Googlebot 仍被允许；如果产品要求“字面意义允许所有爬虫”，需要在 Cloudflare 中关闭 Managed robots.txt / Content Signals 相关设置。仓库文件本身是允许全站的。
