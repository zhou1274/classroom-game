## B2 外链“抄作业”方法手册

这是社区验证过的可执行流程。

### 1. 导出竞品外链

用 Ahrefs 或 Semrush：

- Ahrefs：Site Explorer → 输入竞品域名 → Backlinks
- Semrush：Backlink Analytics → 输入竞品域名 → Backlinks

导出字段建议：

```text
来源域名
来源 URL
目标 URL
锚文本
DR / 权威度
是否 nofollow
```

### 2. 至少分析 3–5 个竞品

从 B1 中选 3–5 个。不要只选一个，否则会偏向头部站点，拿到大量无法复制的链接。

### 3. 合并去重

把多个竞品的外链列表合并：

```text
1. 按来源域名去重
2. 删除 target 指向竞品某个游戏页的链接
3. 删除属于竞品自己站内的链接
4. 删除 spam、目录农场、明显群发站
```

### 4. 按“共同来源数量”排序

排序规则：

```text
来源域名被多少竞品共同拥有
```

例如：

```text
A 站和 B 站都有来自 quora.com 的链接 → 高优先级
只有 A 站有来自某小型目录站的链接 → 低优先级
```

原则：

- 多个竞品都能拿到 → 说明容易获取、成功率高。
- 只有极少数竞品拥有、且来源低质 → 不要碰。

## B3 外链节奏与避坑清单

### 节奏

- 新站先完成少量高质量外链，做到“零的突破”。
- 每天不要超过 3–5 条。
- 头两周每天 1–3 条即可。
- 不要一天内猛发几十条。
- 先低权威度渠道，再逐步增加高 DR 外链。

### 质量匹配

- 新站：目录、社交、问答、教育资源资源页是优先。
- 有一定流量后：再争取 guest post、行业媒体、教育站投稿。
- 不要一开始就追求 DR 90+ 的违和链接，容易被拒。

### 红线

- 不购买垃圾外链。
- 不用链接农场。
- 不用站群互推。
- 不使用隐藏文字、黑帽关键词。
- 不批量购买同一模板的评论链接。

### 效果验证

- 每 1–2 周登录 Search Console →“效果”报告。
- 观察教室类关键词的曝光次数和平均排名。
- 对竞争不激烈的长尾词，少数优质外链就能看到排名上升。
- 没有变化的词不要频繁改内容，先等 2–4 周。
