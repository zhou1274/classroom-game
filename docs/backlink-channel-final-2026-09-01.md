# classroom-game.com 外链渠道定案

日期：2026-09-01
适用站点：https://classroom-game.com
核心关键词：`classroom games unblocked`
定位：非 AI 的免费浏览器游戏门户（B2C，面向学生与老师）
说明：本文件把前面所有渠道评估收敛成最终「该投 / 可投 / 跳过」三档，含实测 rel 属性。可用作执行清单与交接。

---

## 一、结论概览（三档）

| 档 | 渠道 | 一句话 |
| --- | --- | --- |
| 该投（优先） | Product Hunt、PromoteProject、博客评论、Indie Hackers、SaaSHub | 免费、收游戏/网站/独立产品、价值明确 |
| 可投（附加） | AlternativeTo、TIPITY Labs、dev.to、Reddit、Twelve Tools、TinyLaunch | 有价值但条件/优先级低 |
| 跳过 | GetApp、TAAFT、Toolify、Futurepedia、ToolPilot 及榜单内 AI/SaaS/开发者目录 | 不收非 AI 游戏站 / 付费 / nofollow / 不对口 |
| 第二阶段 | 付费外链 | 等 GSC 数据证明有戏再说 |

---

## 二、该投（优先执行）

### 1. Product Hunt（主渠道）
- 入口：producthunt.com/launch
- 免费；个人账号需满 7 天；收 Games 分类
- 链接：nofollow（曝光/引流为主）
- 建议定位“免费课堂浏览器游戏”，降低被拒风险；禁买赞刷票

### 2. PromoteProject（免费 dofollow）
- **实测 dofollow**（链接无 rel="nofollow"）✅
- 免费；DR 约 48；发布板
- 提交：名称 / URL / 一句话简介，发布后请社区 upvote

### 3. 博客评论外链（数量主力）
- 每天 10–20 条；多为 nofollow、少数 dofollow
- 动作流：找可评论博客 → 读文写真人评论 → Website 填 `https://classroom-game.com` → 提交验证 → 记录
- 自动发现循环：从竞品反链滚出更多可评论博客

### 4. Indie Hackers（曝光）
- 免费；DR 约 81；**实测 nofollow**
- 收独立产品；用产品页 + build-in-public 帖

### 5. SaaSHub（曝光）
- 免费；DR 约 79；**实测 nofollow**
- 偏 SaaS；定位为“free browser game platform for classrooms”才有机会过审；需填 Competitors

## 三、可投（附加，优先级低）

| 渠道 | 价值 | 注意 |
| --- | --- | --- |
| AlternativeTo | 免费，DR 约 80 | 需指定“作为哪个站点的替代品”（如 hoodamath.com） |
| TIPITY Labs | 免费，收 games/websites | rel 未实测 |
| dev.to | nofollow，内容分发 | 同步 build-story 技术文，canonical 指向站内原文 |
| Reddit（r/SideProject 等） | nofollow，曝光 | 先参与攒 karma，发“求反馈”帖，别硬甩链接 |
| Twelve Tools | DR 约 81，dofollow 有代价 | 免费提交**要求你挂它的 badge 回链** |
| TinyLaunch | DR 约 62–72，dofollow 有条件 | 免费只给首页曝光；**dofollow 靠 top-3 / 挂 badge 回链 / $39** |

## 四、跳过（附原因）

| 渠道 | 原因 |
| --- | --- |
| GetApp | 官方准则排除聚合站 / 数据库站 / 产品克隆 → 不收游戏门户 |
| There's An AI For That | 只收 AI 工具 + 付费（约 $347 级）+ 免费队列极长 |
| Toolify | 只收 AI 工具 + 付费（$49–$99 加急） |
| Futurepedia | 只收 AI 工具 + 付费（$247–$497）+ **nofollow**（实测） |
| ToolPilot | 只收 AI 工具 + 免费要挂 badge 回链 |
| 榜单内 AI/SaaS/开发者目录 | 如 Future Tools、GPT Demo、SaaS AI Tools、submitaitools、aiagentsdirectory、SourceForge、Hugging Face、Kaggle 等——对非 AI 游戏站不对口 |

## 五、关于那份 601 网站的 bounty 榜单

该榜是**面向 AI/SaaS 产品的通用外链榜**（哥飞社区），绝大多数条目只收 AI 工具或 SaaS。对 classroom-game.com（非 AI 游戏站）**约 90% 不适用**。

- 榜内**值得继续用**的：Product Hunt、Indie Hackers、博客评论渠道（你已在做）。
- 榜内**可顺手试**（非 AI、收网站/可发文）：**listium.com**（可发文 + dofollow）、**alternative.tools**（替代品目录）、startupstash.com、websitelaunches.com。
- 榜内**大量 AI 目录**直接跳过。

结论：**别按这份榜走**，它是为 AI 产品准备的；按本文件三档执行即可。

## 六、执行顺序（优先级）

1. **Product Hunt**（养号满 7 天 → 提交 → 发布日集中推广回评）
2. **PromoteProject**（免费 dofollow，最先拿一条）
3. **博客评论**（每天 10–20 条，最长线）
4. **Indie Hackers / SaaSHub**（产品页 + build-in-public）
5. **dev.to 技术文**（canonical 指向站内原文）
6. 可选：**listium.com / alternative.tools**（免费，可能 dofollow）
7. 第二阶段（GSC 有起色后）：付费外链（5 条标准评估）

## 八、风险红线

- 不买垃圾外链；不做链接农场 / PBN / 站群互推
- 不同一模板批量群发评论
- 不买赞、不刷 upvote、不伪造多条评论
- Reddit 等社区不硬甩链接

---

## 九、第二阶段：付费外链（暂不做）

触发：GSC「效果」出现曝光 + 点击 + 有戏的排名。
标准：DR 不低；来源仍有自然流量；词下能排前；出站域名不多；入站域名多。
策略：多买几个稍便宜 > 买一个贵；`$0.9–$19.9` 批量无用；数量太小不如不花。
